Описание сайта - сайт предназначен для чтения новостей
Как скачать проект - Зайди в мой аккаунт на GitHub, нажми зелёную кнопку «Code» и скопируй HTTPS-ссылку. 
Затем открой терминал и выполни команду git clone скопированная_ссылка.git — проект скачается на твой компьютер. После этого открой папку с проектом и дважды кликни по файлу index.html, чтобы сайт открылся в браузере.
Есть и другой способ: скачай ZIP-архив с проектом, распакуй его и открой в VSCode. Открой встроенный терминал, введи команду npm start, а затем перейди по появившейся ссылке 
либо зажав Ctrl и кликнув по ней, либо скопировав и вставив в браузер.
